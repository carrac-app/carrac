Principles

Decisions that govern every UI surface in Carrac.

Flat with hard offset shadow. No soft drop shadows, no blur, no glassmorphism. Surfaces are flat and the shadow is a 1:1 pixel offset to a solid black box. Read: Bloomberg terminal, not Figma.
Sharp corners (legacy) / one radius (toolbar). main.css still uses border-radius: 1px everywhere. The chart toolbar and drawing tools (.tool-btn, .tf-selector, .indicator-btn, .tool-group-btn, .ind-fav-pill) were re-tokenized in carrac-overhaul.css §21 to share one radius, var(--ctl-r) (6px) — do not add new toolbar controls at 1px, match the token instead.
JetBrains Mono everywhere. Numerical alignment matters more than aesthetics. Sans-serif only on landing/marketing pages.
Toolbar hover is a quiet tint, not a hard shadow. The chart toolbar/drawing-tools row's canonical hover is carrac-overhaul.css §21's background: rgba(255,255,255,.06); color: var(--fg1) (active: rgba(255,255,255,.10)) — this now covers .tool-btn, .tf-selector, .indicator-btn, .tool-group-btn, and .ind-fav-pill/.ind-fav-group identically, so all five read as one control system. DO NOT add new hard-shadow (2px 2px 0 #000) hover rules to toolbar controls — that legacy main.css rule is superseded for this surface, even though it's still declared there (source order lets the overhaul layer win).
One popup style: border: 1px solid #2a2e39; border-radius: 1px; box-shadow: 5px 5px 0 #000;. AI Copilot, asset switcher, ticker settings all use this. DO NOT use rounded corners or soft shadows on new popups.
