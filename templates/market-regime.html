What is a market regime?
2States · HMM · live

The market has moods. Knowing which one you're in changes everything.

A market regime is the underlying character of current conditions — whether the broad environment favours risk-taking or risk-aversion. Prices, correlations, and volatility all behave differently depending on which regime is active.

Regime awareness doesn't tell you what to trade. It describes what kind of market you are trading in; what you do with that is your call.

  • Risk-on: the state the model associates with stronger risk-asset returns, lower volatility and tighter credit spreads
  • Risk-off: the state it associates with weaker risk-asset returns, higher volatility and wider credit spreads
  • The regime is a probabilistic classification — not a certainty, and never a trade recommendation
The live engine

Two-state HMM. Running continuously.

A hidden Markov model is a statistical model that infers a hidden state — in this case, the market regime — from observable signals. Unlike a rule-based system with hardcoded thresholds, an HMM learns the statistical structure of the data and updates its classification as new information arrives.

Carrac's implementation uses a two-state HMM: one state corresponds to conditions generally characterised as risk-on, the other as risk-off. The model runs continuously so the current regime classification is always fresh.

  • Hidden Markov model — learns structure from data, not hardcoded rules
  • Two states — risk-on and risk-off regime classification
  • Live — classification updates continuously as the market moves
  • Probabilistic — a model output, not a certainty or a prediction
  • Part of Carrac's broader quant engine alongside correlations, lead-lag, and anomaly detection
Regime history & transitions

See how the regime has shifted over time.

Regime history gives you the full record of how the HMM has classified conditions over time. You can see when the regime was risk-on, when it flipped to risk-off, how long each state persisted, and how frequently the market has switched between them.

This historical view is useful for understanding what recent market conditions have looked like and for putting the current regime in context — not for predicting what comes next.

Regime transitions surface each moment when the HMM's classification changed — the discrete flip points where conditions shifted from one state to the other. Knowing when transitions have historically occurred can inform how you think about current positioning.

  • Full regime history — time-series record of past classifications
  • Transition log — every regime flip, timestamped
  • Duration data — how long each regime state has lasted
  • Queryable via the Carrac MCP server for AI-assisted analysis

Part of the quant engine

Regime is one layer. The quant engine runs deeper.

The regime surface is one component of Carrac's quant engine — a set of quantitative tools that run continuously across the covered asset universe. Alongside regime detection, the engine includes cross-asset correlations, lead-lag projected moves, transmission chains, anomaly clusters, and a derivatives regime derived from the full options chain.

Each layer adds a different kind of context. Regime tells you the broad character of current conditions; correlations show how assets are moving together; lead-lag and transmission chains map how signals propagate; anomaly detection flags statistically unusual behaviour.

  • Market regime — 2-state HMM: risk-on / risk-off classification
  • Cross-asset correlations — FDR-adjusted significance
  • Lead-lag — projected moves with confidence intervals
  • Transmission chains — how signals travel between assets
  • Anomaly clusters — statistically unusual behaviour across the universe
  • Derivatives regime — from perpetual-futures funding, open interest and long/short balance

All of this is queryable over the Carrac MCP server — bring any MCP-compatible AI client, use your own model and API key, and query the quant engine directly.

Information, not advice

Regime = context. What you do with it is your decision.

Carrac's regime classification is a statistical model output. It describes the current inferred state of the market — it does not tell you whether to buy, sell, hold, or do anything at all. The appropriate response to any regime classification depends entirely on your own strategy, risk tolerance, timeframe, and analysis.
