Getting Started

Custom indicators let you build any calculation from price data and display it on your chart.

  1. Press U or click "Custom" in the indicator menu
  2. Enter a name and formula, e.g. SMA(close, 20)
  3. Choose a display style: line, step line, area, histogram, dots, circles, ref. line, band upper/lower, or signal markers (▲▼ triangles, ↑↓ arrows, ◆ diamond, ✕ cross, ■ square)
  4. Pick a pane: Overlay (on price chart), Shared (grouped with other rows), or Own pane
  5. Save — your indicator appears on the chart immediately
Formulas are case-insensitive: SMA, sma, and Sma all work. Use // or # for comments.
Display Styles

Each formula row has a display style that controls how values are rendered on the chart.

Continuous Styles

LineStandard line connecting each bar's value. The default.
Step LineStaircase pattern — horizontal then vertical between points. Good for discrete-level indicators.
AreaLine with a filled region below it to the bottom of the pane (15% opacity). Great for RSI, volume ratios.
HistogramVertical bars from zero baseline. Green when positive, red when negative.
DotsSmall filled circles at each bar's value.
CirclesLarger hollow circles (stroke only). Good for highlighting sparse data points.
Ref. LineDashed line — use for constant reference levels like RSI 30/70.

Band Styles

Band UpperLine that pairs with a Band Lower row. The area between them fills automatically (12% opacity).
Band LowerThe lower boundary of the band pair. Must be in the same compound indicator as a Band Upper row.
Both band rows should use the same pane setting (e.g. both on Overlay). The fill color comes from the Band Upper row.

Signal Styles — Candle-Relative

Placed at the candle's high or low when the formula value is non-zero. The value is a boolean trigger (0 = no marker, anything else = draw marker). Always placed on the price chart.

▲ Triangle UpSolid triangle below the candle low, pointing up. Conventionally marks a bullish condition.
▼ Triangle DownSolid triangle above the candle high, pointing down. Conventionally marks a bearish condition.
↑ Arrow UpArrowhead with stem below the candle low. Alternative bullish marker.
↓ Arrow DownArrowhead with stem above the candle high. Alternative bearish marker.

Signal Styles — Value-Relative

Placed at the formula's output value (the value IS the Y position). Use IF(condition, price, 0) to place markers at specific price levels. Skipped when value is 0 or NaN.

◆ DiamondFilled diamond at the formula's price level. Neutral signal marker.
✕ CrossStroked X at the formula's price level. Exit or invalidation marker.
■ SquareFilled square at the formula's price level. Alternative marker.
Compound Indicators

Combine up to 6 formulas in a single custom indicator. Each row evaluates independently and can have its own style, color, and pane placement.

How to Create

  1. Open the custom indicator editor (press U)
  2. Enter your first formula with a style and color
  3. Click + Add row to add more formulas
  4. Each row gets its own style dropdown, color picker, and pane selector
  5. Save — all rows appear as a single togglable indicator

Pane Options (per row)

OverlayDraw on the price chart. Best for MAs, bands, signal markers.
Shared paneAll rows set to "Shared" go on the same separate pane. Good for RSI + reference lines together.
Own paneThis row gets its own separate pane below the chart.

Example: EMA Cross System

4-row compound indicator
Two EMAs as lines + crossover/crossunder signal markers. All on overlay.
Row 1: EMA(9) → Line, green, overlay Row 2: EMA(21) → Line, red, overlay Row 3: CROSSOVER(EMA(9), EMA(21)) → ▲ Triangle Up, green, overlay Row 4: CROSSUNDER(EMA(9),EMA(21)) → ▼ Triangle Down, red, overlay

Example: RSI with Zones

3-row compound indicator
RSI as area fill + overbought/oversold reference lines, all on a shared pane.
Row 1: RSI(14) → Area, blue, shared pane Row 2: 70 → Ref. Line, red, shared pane Row 3: 30 → Ref. Line, green, shared pane
Bar Offset Syntax

Access previous bar values with [n] after any expression. Syntactic sugar for OFFSET().

close[1]Previous bar's close (= OFFSET(close, 1))
close[2]Close from 2 bars ago
RSI(14)[1]Previous bar's RSI value
SMA(20)[5]SMA value from 5 bars ago
close[-1]Forward-looking (next bar) — causes lookahead bias in backtests
Offset must be an integer. Works on identifiers, function calls, and parenthesized expressions: (close + open)[1]
Let Bindings

Name intermediate values to keep complex formulas readable. Up to 10 bindings per formula.

Basic let
let mid = EMA(close, 20) let band = ATR(14) * 1.5 CROSSOVER(close, mid + band)
Let with bar offset
let rsi = RSI(14) let prev_rsi = rsi[1] rsi > 30 AND prev_rsi <= 30
Syntaxlet name = expression — no separator needed between lets
ScopeSequential: each let sees all previous bindings
ShadowingAllowed: let x = 5 let x = x + 1 → x is 6
OutputThe last expression (after all lets) is the formula's result

Price Action

Building blocks for the price-action patterns many traders trade around. Each returns 1 on bars where the pattern completes, 0 elsewhere — combine them with any other function. The names in brackets are the same patterns under their Smart Money Concepts labels; both spellings work.

These describe daily and hourly behaviour. The techniques they come from were built for 5- and 15-minute charts, which Carrac does not store data for — so treat the results as what the pattern did on the bars you actually have, not as a verdict on the original method.

GAP_UP(atr_mult=0.25)Bullish 3-bar imbalance — the low sits above the high two bars back. Gaps smaller than atr_mult × ATR(14) are ignored, matching the Fair Value Gap indicator on the chart. Pass 0 for every gap. Also: FVG_UP()
GAP_DOWN(atr_mult=0.25)Bearish 3-bar imbalance — the high sits below the low two bars back. Also: FVG_DOWN()
SWEPT_LOW(period=20)Breaks the lowest low of the last period bars, then closes back above it — a failed breakdown. Also: LIQUIDITY_SWEEP_LOW()
SWEPT_HIGH(period=20)Breaks the highest high of the last period bars, then closes back below it. Also: LIQUIDITY_SWEEP_HIGH()
DISPLACEMENT(mult=2.0)An outsized bar — its range beats mult × the previous bar’s ATR(14). Measured against the previous bar so a big candle cannot raise its own bar.
REVERSAL_CLOSE_UP(count=2)count red bars in a row, then a close above all their highs. Red means the bar closed below its own open. Also: CSD_UP()
REVERSAL_CLOSE_DOWN(count=2)count green bars in a row, then a close below all their lows. Also: CSD_DOWN()

Order blocks are not here. The chart draws them as zones anchored to a break in market structure, and tracks whether price has since traded back through them. That is a richer thing than any single-bar test, so it stays on the chart rather than being approximated into a formula that would mean something different under the same name.

CPR_S1() / CPR_S2() / CPR_S3()Support levels 1-3

Example Recipes

Click any formula to copy it. Paste into the editor and adjust parameters to taste.

Bollinger Band Width %
How wide are the bands relative to price? Low values signal a squeeze incoming.
(BB_UPPER(close, 20, 2) - BB_LOWER(close, 20, 2)) / SMA(close, 20) * 100
EMA Ribbon Spread
Distance between fast and slow EMA. Positive = bullish, negative = bearish.
EMA(close, 8) - EMA(close, 34)
Volume Spike Detector
Highlights bars with 2x average volume. Use histogram style.
IF(volume > SMA(volume, 20) * 2, volume, 0)
RSI Oversold Bounce
Marks bars where RSI crosses back above 30 (potential reversal). Use ▲ Signal Up style.
CROSSOVER(RSI(close, 14), 30)
EMA Crossover Signals
Green triangle below bar when fast EMA crosses above slow. Use ▲ Signal Up style on overlay.
CROSSOVER(EMA(9), EMA(21))
EMA Crossunder Signals
Red triangle above bar when fast EMA crosses below slow. Use ▼ Signal Down style.
CROSSUNDER(EMA(9), EMA(21))
RSI Area
RSI as filled area — easier to spot overbought/oversold zones. Use Area style in own pane.
RSI(14)
RSI Reference Levels
Constant at 70 (overbought) or 30 (oversold). Use Ref. Line style, place on same pane as RSI.
70
Support Touch Markers
Diamond at the 200-SMA when price touches it. Use ◆ Diamond style — the value is the Y position.
let sma = SMA(close, 200) IF(ABS(low - sma) / sma < 0.005, sma, 0)
Exit Crosses
✕ at close when RSI exits overbought. Use Cross style — marks invalidation points.
IF(CROSSUNDER(RSI(14), 70), close, 0)
Bollinger Band Fill
Two-row compound indicator: Row 1 = Band Upper style, Row 2 = Band Lower style. Automatically fills between them.
Row 1: BB_UPPER(close, 20, 2) → Band Upper Row 2: BB_LOWER(close, 20, 2) → Band Lower
Keltner Channel Band
EMA ± ATR channel with shaded fill. Use Band Upper/Lower styles in a compound indicator.
Row 1: EMA(20) + ATR(14) * 1.5 → Band Upper Row 2: EMA(20) - ATR(14) * 1.5 → Band Lower
Squeeze Detector
1 when Bollinger Bands are inside Keltner Channels (volatility compression). Use histogram.
IF(AND(BB_UPPER(close,20,2) < KELTNER_UPPER(20,1.5), BB_LOWER(close,20,2) > KELTNER_LOWER(20,1.5)), 1, 0)
Relative Volume
Volume as multiple of its 20-bar average. 2.0 = double normal.
volume / SMA(volume, 20)
MACD Histogram
Classic MACD histogram — look for shrinking bars for divergence signals.
MACD_HIST()
Multi-Timeframe Trend Filter
1 when price is above both 50 and 200 SMA = confirmed uptrend. Use histogram.
IF(AND(close > SMA(close, 50), close > SMA(close, 200)), 1, 0)
Volatility-Adjusted Momentum
ROC normalized by ATR — compare momentum across different volatility regimes.
ROC(close, 14) / ATR(14)
Mean Reversion Signal (Z-Score)
Z-score of close relative to 50-bar SMA. Beyond ±2 = stretched.
(close - SMA(close, 50)) / STDEV(close, 50)
Donchian Channel Width
Width of the 20-bar high-low channel as % of price. Compression = breakout setup.
(HIGHEST(high, 20) - LOWEST(low, 20)) / close * 100
Cumulative Delta Proxy
Running sum of directional volume. Poor man's CVD.
SUM(IF(close > open, volume, -volume), 50)
RSI Oversold Bounce (with let)
Signal where RSI crosses back above 30. Uses let + bar offset for clarity.
let rsi = RSI(14) let prev = rsi[1] rsi > 30 AND prev <= 30
Keltner Squeeze with Momentum
Squeeze detection with MACD direction. Uses let to avoid repeating calculations.
let squeeze = AND(BB_UPPER(close,20,2) < KELTNER_UPPER(20,1.5), BB_LOWER(close,20,2) > KELTNER_LOWER(20,1.5)) let mom = MACD_HIST() IF(squeeze, mom, 0)
Backtest Models

Carrac exposes three different backtest models. They answer different questions and will usually produce different numbers on the same formula — always check which model you’re reading.

Model Where What it does
Full Simulation Backtester UI (Run button) Trade-by-trade simulation with separate entry + exit formulas, position sizing, commission, slippage, intrabar stops/take-profit. Reports win rate, Sharpe, Sortino, Calmar, Ulcer, profit factor, drawdown. This is what you use to evaluate an actual trading strategy.
Hold-N Signal Test Hold-N card in results · AI Copilot · MCP backtest_indicator_formula Directional setup test: on each False→True flip of a single boolean expression, hold N bars and record the forward return. Reports hit rate, mean/median return. Cheap and quick — use to compare setup ideas. Not a full strategy sim.
Historical Analog Historical Analog panel (below stats) · MCP backtest_get_historical_analog Quant DB conditional engine: “when these macro / indicator conditions held in the past, how did the target asset move over the next N days?” Returns a distribution (median, p25, p75) of forward returns. Macro-regime context, not a trade sim.

A Hold-N hit rate and a Full Sim win rate measure different things — don’t compare them directly. A Hold-N flip does not use your exit formula, sizing, or fees.

Tips & Limitations
Formulas evaluate in under 1ms per indicator on 2500 bars. You won't notice any lag.
  • No loops — use let bindings to name intermediate values (up to 10 per formula).
  • Max length: 2000 characters per formula.
  • Max nesting: 20 levels deep, 50 function calls per formula.
  • NaN gaps: The first N bars (lookback period) produce NaN and render as gaps in the line. This is normal.
  • Division by zero produces NaN (gap), not an error.
  • Signal outputs (0/1 values) auto-detect: the editor suggests a signal style like ▲ Up or ▼ Down.
  • Compound indicators: Click "+ Add row" to combine multiple formulas (e.g. EMA ribbon + crossover signals) in a single custom indicator. Max 6 rows.
  • Pane options: Overlay (on price chart), Shared (all rows share one pane), Own (separate pane per row).
  • Band fill: Set one row to Band Upper and another to Band Lower — the area between them fills automatically. Both rows should be on the same pane.
  • Limits: Free accounts: 3 custom indicators. Premium: 10. Admin: 20.
  • Sharing: Copy the formula text and paste it in Discord/chat. The recipient pastes it into their own editor.
