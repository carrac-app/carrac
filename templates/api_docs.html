Webhooks

Carrac can push every triggered alert — price, trendline, indicator, formula, z-score, regime-change, derivatives, chain-strength, anomaly-cluster, conditional-query, and play alerts — to a single HTTPS endpoint you configure in Settings → Notifications → Webhook (paid plans). This is outbound-only: Carrac calls your endpoint, there is nothing to call on Carrac's side.

Request

  • POST to your configured URL — HTTPS only, redirects are never followed
  • Content-Type: application/json
  • X-Carrac-Signature: hex HMAC-SHA256 of the raw request body, keyed with your webhook secret
  • 5 second timeout, up to 3 retries with exponential backoff
  • After 10 consecutive delivery failures the webhook is automatically disabled and you're notified on another configured channel

Payload

{
  "alert_id": 123456,
  "alert_type": "price",
  "symbol": "BTCUSDT",
  "condition": "BTCUSDT is now $65,000.00 (above $64,000.00)",
  "price": 65000.0,
  "triggered_at": "2026-07-18T09:32:11Z",
  "link": "{{ site_url }}/?symbol=BTCUSDT"
}
Field Type Description
alert_id integer The alert that fired.
alert_type string e.g. price, trendline, indicator, formula, zscore, regime_transition, play.
symbol string Asset symbol, or a fixed label (REGIME, ANOMALY, CHAIN, CONDITION) for non-symbol alert types.
condition string Human-readable summary of what triggered.
price number Price at trigger time, when applicable (0 for alert types with no single price, e.g. regime-change).
triggered_at string ISO-8601 UTC timestamp.
link string Absolute link back into the app for this symbol/alert.

Verifying the signature (Python)

import hashlib
import hmac

def verify_carrac_signature(raw_body: bytes, signature_header: str, secret: str) -> bool:
    """raw_body must be the exact request body bytes — do not re-serialize
    the parsed JSON, whitespace/key-order differences will break the check.
    signature_header is the X-Carrac-Signature request header.
    secret is your webhook signing secret from Settings → Notifications.
    """
    expected = hmac.new(secret.encode("utf-8"), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature_header)
