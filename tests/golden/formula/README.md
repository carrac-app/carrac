# Formula Parity Golden Fixtures

Pinned expressions × OHLCV fixtures → canonical output arrays.

Regenerated by running `tests/golden/formula/regenerate.py`. Expected values
come from the current Python `formula_eval` implementation (source of truth for
this release). Both Python and JS evaluators must match these outputs.

Files:
- `fixtures.json` — input OHLCV snapshots and expression list
- `expected.json` — canonical outputs from Python evaluator
- `regenerate.py` — regenerates expected.json (run when intentionally changing semantics)

Tests:
- `tests/test_formula_parity.py` — Python side; verifies current implementation
  produces the golden outputs.
- `tests/parity/formula.parity.test.mjs` — Node-runnable JS side; shares the
  fixtures and asserts within tolerance.

Tolerance: 1e-6 absolute. Anything beyond indicates drift.
