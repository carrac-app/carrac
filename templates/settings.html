  5. Paste both values above
Webhook
?

Send every triggered alert as a signed JSON POST to your own endpoint — price, trendline, indicator, formula, z-score, regime-change, and play alerts all fire here.

  1. Enter your HTTPS endpoint URL above and enable the toggle, then Save
  2. A signing secret is generated automatically the first time — copy it now, it is only shown once
  3. Verify each request's X-Carrac-Signature header (hex HMAC-SHA256 of the raw body using your secret) — see the API docs for a Python example
  4. After 10 consecutive delivery failures the webhook auto-disables and you'll be notified on another channel
Exchange Sync
Journal Auto-Sync ?

Connect a read-only Binance or Hyperliquid account and Carrac imports your fills into the journal automatically, every 15 minutes — no manual logging.

  1. Binance: create an API key with only "Enable Reading" checked (no trading, no withdrawals) and paste the key + secret below. Carrac verifies the key is read-only before saving it, and rejects any key with elevated permissions.
  2. Hyperliquid: paste your wallet address — fills are public on-chain, so no secret is ever needed or stored.
  3. A fill that looks like it might already be one of your manual entries is held as a suggestion instead of imported automatically — you choose "import anyway" or "skip".

API & MCP Keys

            

                

                    One key, two doors: the same key authenticates both the
                    REST API ({{ site_host }}/api/...) and the MCP server ({{ site_host }}/mcp)
                    used by AI assistants — there is no separate “MCP key”. Keys inherit your account tier and rate limits.
                

                

                    For security, keys are stored hashed — each key is shown only once,
                    right after creation. Lost a key? Revoke it and create a new one.

Fastest path: let your agent set itself up

                    

                        Copy a ready-made prompt with the endpoint, auth header and setup steps, and paste it into
                        Claude Code, Claude Desktop, Cursor or any MCP-capable agent — it will wire up the connection itself.
                        If you just created a key above, your key is filled in automatically; otherwise replace
                        YOUR_CARRAC_API_KEY with one of your keys.

    }
  }
