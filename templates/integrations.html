Gemini · Cursor · Any MCP client

Prompting with your book vs. prompting in a vacuum.

MCP is a protocol, not a product. Gemini’s CLI, Cursor, and any other MCP-compliant client point at the same {{ site_url }}/mcp endpoint with the same API key. One integration, many clients.

Prompting without MCP

  • Screenshot chart, paste into chat
  • Copy scanner row text manually
  • Paraphrase your own plays from memory
  • Stale data — whatever you screenshotted
  • Model has to infer structure from prose

Prompting with Carrac MCP

  • Live chart data via market_get_chart
  • Structured scanner output via scanner_get_screen
  • Your open plays via play_list
  • Real-time regime via quant_get_regime
  • Model reasons with typed tool responses

Using Cursor? Add the MCP server under Cursor → Settings → MCP with the same {{ site_url }}/mcp URL and your API key. Carrac tools then appear in Cursor’s tool list automatically.

No screenshots. No translation layer. Just questions → answers → decisions.
